# Minor_Project-Clinical-SAS
SAS programming project using SASHELP.CLASS and SASHELP.CLASSFIT to create a student master dataset, derive BMI and student-related variables, analyze weight differences, and create filtered student datasets using SAS programming techniques.

SAS Programming – Student Analysis Project
Project Overview

This project demonstrates Base SAS programming using the SASHELP.CLASS and SASHELP.CLASSFIT datasets. The project combines student demographic and fitness information, creates derived variables such as BMI and Age Group, performs weight analysis, and creates additional datasets based on defined conditions.

Objectives :
Combine student and fitness information
Calculate BMI and classify BMI status
Create student age groups
Generate unique Student IDs
Create name-related derived variables
Calculate the difference between actual and predicted weight
Determine Final Weight
Create filtered student datasets
Handle missing values and ensure unique Student IDs
Apply appropriate labels, formats, and variable ordering
